# TicTacToe

Un morpion jouable contre l'ordinateur écrit en Python avec Tkinter.
L'ordinateur place son pion aléatoirement sur une case libre.

## Lancer le jeu

1. **Récupérer le projet** :
```
git clone https://github.com/kbh77-dot/tictactoe.git
```

2. **Lancer l'application** : 
```
python main.py
```

3. **Jouer** : 
choisir son symbole (X ou O) puis cliquer sur une case. X commence toujours la partie. Le bouton *Rejouer* relance une partie sans quitter l'application et *Changer de symbole* revient au menu pour changer de symbole.
